## 3. NID-24 (Next-gen Interface Device)
!!! warning "Status: Under Active Development"
    - **Concept:** EMG-based Human-Device Interface (HDI)
    - **Hardware:** Muscle sensors + Signal processing
    - **Repo:** [:octicons-mark-github-16: Raghav67816/NID-24](https://github.com/Raghav67816/NID-24)

NID-24 is my current research project into gesture-based computing. It utilizes **Electromyography (EMG)** to capture electrical activity from human muscles, allowing for device control without physical touch or cameras. I am currently working on the PCB design because it is most fundamental part of this project.
