    My Garage

    A collection of systems, frameworks, and hardware-software interfaces I have built. I focus on building tools that are fault-tolerant, accessible, and low-level.

    Each award winning project was a year long journey which came with lessons that really changed me. I have put those stories in my book so it's worth reading the chapters.

    I also have unshipped projects on my GitHub which includes some projects that I made for inter-school competitions. I won them mostly but never got the 1st position. I haven't got my certificates yet.

    AVERAGE INDIAN SCHOOL COMEPTITIONS

    1. Vulture OS

    National Finalist: IIT Bombay Techfest 2022

    • Award: Budding Innovator
    • Concept: Fault-tolerant Home Automation OS
    • Stack: C++, Qt Framework
    • Status: Shipped (Legacy), I didn't know about Github and Git that much.

    Vulture OS was a home automation platform/OS which my first piece of fault-tolerant system. I began ideating when my IoT project failed at school exhibition. I was just super furious on Blynk, and still I am because of their new business model.

    But this project won 2 awards - Youngest National Finalist & Budding Innovator at IIT Bombay Techfest 2022

    PS: This project also failed during final presentation because of a network authentication protocol which I didn't account for it was a commercial network I was trying to connect to and it failed.

    2. Project "Key" (IFT Season 3)

    National Top 6 Finalist

    • Competition: India's Future Tycoons (IFT) Season 3
    • Visibility: Featured on CNN Mirror Now
    • Status: Shipped (Legacy), I still didn't know about Github and Git that much.

    During lock-down I started my journey as a programmer, online classes were difficult for teachers because they were not really used to computers. So, me and my friend made this application which bought all the tools at one place with simple interface making online classes a bit efficient.

    PS: This also failed during final presentation due to the way I configured speech recognition module.

    3. NID-24 (Next-gen Interface Device)

    Status: Under Active Development

    • Concept: EMG-based Human-Device Interface (HDI)
    • Hardware: Muscle sensors + Signal processing
    • Repo: Raghav67816/NID-24

    NID-24 is my current research project into gesture-based computing. It utilizes Electromyography (EMG) to capture electrical activity from human muscles, allowing for device control without physical touch or cameras. I am currently working on the PCB design because it is most fundamental part of this project.

    4. The Layman's AI Framework

    Status: Shipped

    • The Goal: Making Neural Networks transparent for students.
    • Stack: Python, Custom Math/Linear Algebra
    • Repo: Raghav67816/The-Layman-AI-Framework

    I love this one, so basically our education board's curriculum for AI is really worse, and we have been studying the same thing in AI for past 4 years and we were using some really useless tools like teachable machines which give you surface level knowledge only. But using intermidiate or advanced tools was not an option either.

    So, with the help of my teacher, I studied learning patterns of my batchmates, and made a tensorflow but the simplest version such that it matches the language written in the worst book I have ever read.

    PS: This one rocked. I got 50/50 with this project in my final exams.

    5. TARS Communication Protocol

    Status: Shipped

    • The Hook: A phone inside your terminal.
    • Stack: Python, Socket Programming, Audio Encoding
    • Repo: THE-TARS-PROJECT/tars-comm

    Most of my projects after 2024 are inspired by sci-fi movies. I was watching Tony Stark and Ivan Vonko talking on through that sci-fi ui interface. So, I decided to make one.

    This is a terminal based voice-over-ip application that is like a phone (including phone book) but lives in your terminal

    6. Bio-Silicon Synergetic Intelligent System

    Status: Shipped

    • The Science: EEG Data Analysis for Neuro-research
    • Focus: Fault-tolerant Signal Processing
